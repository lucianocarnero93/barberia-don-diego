Landing page para Barbería Don Diego en la ciudad de Santa Fe, los requisitos son solamente un navegador web moderno y un servidor local. Para levantar este proyecto solo hay que modificar precios y estilos, fotos con la barbería que utilice el servicio y adecuarse a los usuarios que tenga la barbería.
https://github.com/lucianocarnero93/barberia-don-diego
Ese es el repositorio publico con todas las modificaciones de la pagina, la ultima modificación fue el README.TXT.
Para que la pagina sea publica utilizamos Github que es un hosting gratuito que nos permitió subir el proyecto para acceso publico.
Esta landing page es creada para que la barbería pueda competir mostrando sus servicios, interactuando con los clientes 24/7, obtener claridad a la hora de mostrar los precios y servicios, mostrar su trabajo y tener una organización precisa de los turnos de la barbería.
Con esta pagina la barbería va a poder tener en cualquier momento del día tanto reserva como ventas, como también publicidad.
